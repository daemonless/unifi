## Deployment

### Podman Compose

```yaml
services:
  unifi:
    image: ghcr.io/daemonless/unifi:latest
    container_name: unifi
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=UTC
    volumes:
      - /path/to/containers/unifi:/config
    ports:
      - 8443:8443
      - 8080:8080
      - 8843:8843
      - 8880:8880
      - 6789:6789
      - 3478:3478
      - 10001:10001
    annotations:
      org.freebsd.jail.allow.mlock: "true"
    restart: unless-stopped
```

